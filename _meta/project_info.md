## Description
Felt is a featherweight, distraction-free native Qt 6 markdown writing instrument. It serves as an unbloated alternative to iA Writer, offering an obsidian `#080808` canvas, true paragraph/sentence focus mode, typewriter scrolling, and in-situ styling for the Essential 5 Markdown constructs without HTML conversion overhead.
